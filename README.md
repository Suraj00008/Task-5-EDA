# Titanic Dataset EDA

## Objective
Perform Exploratory Data Analysis (EDA) on the Titanic Dataset to identify patterns, trends, and relationships.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VS Code

## Analysis Performed
- Data Inspection using head(), info(), describe()
- Missing Value Analysis
- Survival Count Analysis
- Histogram (Age Distribution)
- Boxplot (Fare Distribution)
- Survival by Gender
- Survival by Passenger Class
- Correlation Heatmap
- Pairplot
- Scatter Plot (Age vs Fare)

## Key Findings
1. Most passengers were between 20 and 40 years old.
2. Fare contains several outliers.
3. Female passengers survived more frequently than males.
4. First-class passengers had higher survival rates.
5. Higher fares were associated with better survival chances.
6. Missing values were present in Age, Cabin, and Embarked columns.

## Conclusion
EDA helped identify important survival patterns and relationships within the Titanic dataset.
